# Write it down, make it clear

A quiet place to focus on your words.

## Start here

Type Markdown directly and see its formatting when the cursor moves away. Try **bold**, *italic*, `inline code`, and the [Markdown guide](https://commonmark.org/help/).

- Everything stays in local files
- Press ⇧⌘M to switch between source and formatted text
- Press ⌘S to save and ⌘F to find text

## Today's plan

1. Capture an idea
2. Turn it into a paragraph
3. Leave time to revise

> Writing turns a vague thought into something concrete.

```swift
let thought = "Start with one sentence."
print(thought)
```

## Find your way

Press ⌃⌘S to show the sidebar. Use the list icon to jump between sections. The document icon shows recent files; right-click one to pin it at the top.

Now place the cursor here and start writing.
