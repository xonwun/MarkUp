# MarkUp app icon

Created using the built-in image generation tool. Master: `MarkUp-icon.png` (RGBA, transparent background). App bundle uses `AppIcon.icns`, with 16–1024 px representations. Run `./scripts/build-icon.sh` from the project root to regenerate from the master. Intermediate icon sizes are generated in `.build/AppIcon.iconset/`, keeping this folder limited to the master, packaged icon, and design notes.

Design: warm ivory rounded tile, softly raised folded paper, dark muted teal Markdown emblem. Original artwork inspired by the restrained dimensional treatment of macOS productivity icons.

## Generation prompt

Use case: logo-brand. Create one finished macOS desktop app icon for MarkUp, a lightweight Markdown writing editor. Square 1024x1024 production icon, genuinely transparent outside the icon. Inspired by the restrained dimensional craft of macOS built-in productivity app icons, but original design. Centered front-facing continuous rounded-square tile occupying about 84% of canvas with equal transparent margins. Warm ivory porcelain/paper tile, subtly beveled edges, soft ambient shadow. Within it, a single clean white sheet of paper with a tiny folded upper-right corner, very subtle relief. One bold beautifully geometric dark muted teal Markdown emblem centered on the paper: capital M with a simple upward arrow immediately to its right, integrated as a single balanced symbol. Below emblem two short very subtle embossed horizontal writing lines. Extremely simple, quiet, premium, tactile. Strong silhouette and legibility at 32px. No pencil, no extra objects, no words, no app name, no border frame, no watermark, no surrounding scene, no perspective tilt, no photorealistic desk. Only a single icon, not a presentation or grid. Preserve true alpha outside rounded tile and soft shadow.

## Arrow direction revision

Edited with the built-in image generation tool: change only the arrow next to M to point upward, retaining its teal color, weight, paper, folded corner, ivory tile, lighting and transparency. The upward arrow represents MarkUp.
